# North Africa 30×30 dashboard, with OECM opportunities (Tunisia)

The North Africa 30×30 dashboard (WWF version) with its **OECM opportunities** page: which sites in Tunisia could become OECMs,
what they would add to GBF Headline Indicator 3.1, and which Key Biodiversity Areas they would cover. Pages: Overview, Country,
OECM opportunities, Compare, Report, Methodology.

Static site, no build step: run locally with `python3 -m http.server` (http://localhost:8000), hosted on Vercel.

Screening for discussion, not an OECM assessment. KBA content © KBA Partnership (World Database of KBAs terms of use);
WDPA content: UNEP-WCMC terms. The WWF logo and font belong to WWF.
